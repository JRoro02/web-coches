# AutoElite — Web de Coches de Alta Gama

Sitio web desarrollado en HTML y CSS para una empresa ficticia de coches 
de alta gama, con diseño enfocado en potencia y elegancia.

🔗 **Sitio publicado:** https://jroro02.github.io/web-coches/

## 📄 Páginas
- **Inicio** — Presentación de la marca y sus servicios
- **Productos** — Galería de vehículos disponibles
- **Presupuesto** — Formulario para solicitar presupuesto personalizado
- **Contacto** — Información y formulario de contacto

## 🛠️ Tecnologías
`HTML5` `CSS3`

## 🚀 Despliegue
Publicado con GitHub Pages directamente desde este repositorio.
